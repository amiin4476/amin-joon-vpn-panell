# AMIN JOON – Advanced VPN Management System

**پنل مدیریت متمرکز و چندسروری VPN | رایگان، متن‌باز و چندزبانه**

AMIN JOON یک پروژه متن‌باز برای مدیریت متمرکز سرویس‌های VPN، کاربران، نمایندگان و سرورهای مختلف است.

هدف پروژه ارائه یک سیستم کامل، قابل توسعه و قابل نصب روی سرور شخصی هر کاربر است؛ بدون نیاز به سرور مرکزی متعلق به توسعه‌دهنده و بدون نسخه پولی یا محدودیت Pro.

**زبان پیش‌فرض:** فارسی (RTL)  
**زبان دوم:** English  
**مجوز:** GNU AGPL-3.0

---

## اصول پروژه

- کاملاً رایگان و متن‌باز
- بدون نسخه Pro، لایسنس پولی یا کلید فعال‌سازی
- دسترسی عمومی به امکانات و کد منبع
- امکان نصب مستقل روی سرور شخصی
- امکان مشارکت و توسعه توسط برنامه‌نویسان
- حفظ امنیت و حریم خصوصی اطلاعات کاربران

توجه: رایگان بودن نرم‌افزار به معنی رایگان بودن هزینه سرور، دامنه و زیرساخت شبکه نیست.

## امکانات هدف

### مدیریت سرورها
- مدیریت چندین Node در کشورهای مختلف
- افزودن، ویرایش و حذف Node
- نمایش کشور، شهر، IP و وضعیت سرورها
- مانیتورینگ CPU، RAM، Disk و ترافیک
- بررسی سلامت و ارتباط Nodeها

### مدیریت پروتکل‌ها
- Xray / V2Ray
- WireGuard
- OpenVPN
- L2TP/IPsec
- Backhaul

### مدیریت کاربران و اشتراک‌ها
- ساخت و مدیریت حساب کاربران
- اشتراک چندلوکیشنی
- نمایش حجم مصرفی و حجم باقی‌مانده
- تاریخ انقضا و تمدید حساب
- لینک اتصال و QR Code

### مدیریت نمایندگان
- پنل اختصاصی نمایندگان
- تعیین سهمیه کاربران
- تعیین محدودیت حجم و زمان
- تعیین تعداد اتصال هم‌زمان
- تعیین پروتکل‌های مجاز

### ربات تلگرام
- فروش خودکار سرویس
- تمدید و افزایش حجم
- تحویل اطلاعات اتصال
- مدیریت سفارش‌ها و پرداخت‌ها

### مدیریت و امنیت
- نقش‌های کاربری و سطح دسترسی
- ثبت رویدادها و گزارش فعالیت‌ها
- پشتیبان‌گیری و بازیابی اطلاعات
- مدیریت Inbound، Outbound و Routing

## فناوری‌های مورد استفاده

| بخش | فناوری |
|---|---|
| Backend | Python / FastAPI |
| Database | PostgreSQL |
| Cache / Queue | Redis |
| Frontend | React / TypeScript |
| UI | Tailwind CSS |
| Deployment | Docker Compose |
| Node Agent | Python |
