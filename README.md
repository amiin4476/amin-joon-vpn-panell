# AMIN JOON VPN Panel

پنل مدیریت متمرکز و چندسروری VPN با رابط فارسی (RTL).

> وضعیت: اسکلت اولیه پروژه (Phase 0). این نسخه هنوز برای فروش یا مدیریت سرور عملیاتی آماده نیست و هیچ تغییری روی سرویس‌های VPN سرور ایجاد نمی‌کند.

## اهداف اصلی
- مدیریت مرکزی چند Node در کشورهای مختلف
- مدیریت Inbound / Outbound و Routing
- WireGuard، Xray، OpenVPN، L2TP/IPsec و Backhaul
- کاربران، اشتراک چندلوکیشنی و QR Code
- نمایندگان با محدودیت تعداد کاربر، حجم، زمان و اتصال
- ربات تلگرام فروش و تمدید
- داشبورد مانیتورینگ CPU، RAM، Disk، شبکه و وضعیت سرویس‌ها
- فارسی RTL به‌عنوان زبان پیش‌فرض و انگلیسی به‌عنوان زبان دوم

## معماری پیشنهادی
- Backend API: Python + FastAPI
- Database: PostgreSQL
- Queue / Cache: Redis (در فازهای بعد)
- Frontend: React + TypeScript + Tailwind (در فاز بعد)
- Node Agent: سرویس مستقل روی هر نود؛ ارتباط امن و احراز هویت‌شده با پنل مرکزی
- Deployment: Docker Compose

## اجرای محیط توسعه
نیازمند Docker و Docker Compose است:

```bash
cp .env.example .env
docker compose up --build
```

سپس:
- API: http://localhost:8000
- Health: http://localhost:8000/health
- مستندات API: http://localhost:8000/docs

## ساختار
```text
backend/       API و منطق اصلی
frontend/      رابط کاربری (در فاز بعد)
agents/        عامل مدیریت نودها و اتصال پروتکل‌ها (در فازهای بعد)
docs/          طراحی معماری و قراردادها
```

## امنیت و اصول طراحی
- کلیدها، رمزها و توکن‌ها فقط در Secret/Environment نگهداری شوند؛ هرگز در Git ثبت نشوند.
- ارتباط پنل و Node Agent باید TLS و احراز هویت متقابل/توکن چرخشی داشته باشد.
- Agent فقط فرمان‌های allowlist شده را اجرا کند؛ اجرای shell دلخواه از API ممنوع است.
- هر عملیات تغییردهنده روی سرور باید audit log و امکان بررسی نتیجه داشته باشد.
- محدودیت‌های نماینده باید در Backend enforce شوند، نه فقط در رابط کاربری.
- ساخت اکانت باید idempotent باشد و در برابر retry اکانت تکراری نسازد.

## نقشه راه
1. هسته پنل، احراز هویت، نقش‌ها، دیتابیس و داشبورد
2. ثبت Node و مانیتورینگ امن
3. مدیریت Inbound و اتصال تدریجی پروتکل‌ها
4. Outbound، Routing و تونل بین نودها
5. Subscription و صفحه کاربر
6. نمایندگان و سهمیه‌ها
7. ربات تلگرام و پرداخت
8. تست امنیت، بکاپ/بازیابی و انتشار

## وضعیت پیاده‌سازی
فعلاً فقط اسکلت API و سلامت سرویس پیاده‌سازی شده است. هیچ ادعایی درباره اتصال عملیاتی WireGuard/Xray/OpenVPN/L2TP یا Backhaul در این نسخه وجود ندارد.
