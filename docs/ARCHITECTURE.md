# معماری AMIN JOON

## کنترل‌پلین و نودها
پنل مرکزی نقش Control Plane را دارد و وضعیت، کاربران، سیاست‌ها و تنظیمات را نگهداری می‌کند. هر سرور VPN یک Node Agent مستقل دارد که فقط عملیات مجاز و تعریف‌شده را اجرا می‌کند.

## چرخه افزودن نود
1. مدیر از پنل درخواست ثبت نود ایجاد می‌کند.
2. پنل یک enrollment token کوتاه‌عمر و یک‌بارمصرف صادر می‌کند.
3. Agent با TLS به پنل متصل و هویت خود را ثبت می‌کند.
4. پنل کلید/گواهی اختصاصی نود را صادر و توکن enrollment را باطل می‌کند.
5. Agent heartbeat و telemetry را ارسال می‌کند.

## مدل مفهومی
- ServerNode: نام، کشور، شهر، IP مدیریت، وضعیت، نسخه Agent، ظرفیت و آخرین heartbeat
- Inbound: نود، پروتکل، پورت، تنظیمات و وضعیت
- Outbound: نوع خروجی، نود/مقصد، تنظیمات محرمانه و وضعیت
- Customer: شناسه، وضعیت و مالک
- Subscription: توکن تصادفی، تاریخ شروع/انقضا و سیاست مصرف
- Reseller: سهمیه کاربر، حجم، زمان و سطح دسترسی
- AuditEvent: عامل، عملیات، هدف، نتیجه و زمان

## اصل امنیتی
هیچ endpoint عمومی نباید فرمان shell آزاد دریافت کند. برای هر پروتکل adapter مستقل با عملیات محدود، اعتبارسنجی ورودی و تست نوشته می‌شود.
